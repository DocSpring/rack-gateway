The `rack-gateway` CLI is distributed as a single binary. Choose the installation method that works best for your platform.

## Download from GitHub Releases (Linux x86_64)

Each release publishes a Linux x86_64 build with a checksum and a signed build provenance attestation:

```bash
VERSION=v0.1.10  # see https://github.com/docspring/rack-gateway/releases
curl -fsSLO https://github.com/docspring/rack-gateway/releases/download/$VERSION/rack-gateway-linux-amd64.tar.gz
curl -fsSLO https://github.com/docspring/rack-gateway/releases/download/$VERSION/rack-gateway-linux-amd64.tar.gz.sha256
sha256sum --check rack-gateway-linux-amd64.tar.gz.sha256
gh attestation verify rack-gateway-linux-amd64.tar.gz --repo DocSpring/rack-gateway
tar xzf rack-gateway-linux-amd64.tar.gz
sudo install -m 0755 rack-gateway-linux-amd64 /usr/local/bin/rack-gateway
```

The release build has no WebAuthn support (no CGO), so it verifies MFA with TOTP, YubiKey OTP or backup codes. To
use a security key from the CLI, or on macOS and other platforms, [build from source](#building-from-source).

## Verify Installation

```bash
rack-gateway version
```

You should see output like:

```
client: v0.1.10
gateway: (not logged in)
server: (not logged in)
```

## Shell Completion

The CLI supports shell completion for bash, zsh, fish, and PowerShell.

<Tabs>
  <TabItem label="Bash">
    ```bash
    # Add to ~/.bashrc
    source <(rack-gateway completion bash)

    # Or generate a file
    rack-gateway completion bash > /etc/bash_completion.d/rack-gateway
    ```
  </TabItem>
  <TabItem label="Zsh">
    ```bash
    # Add to ~/.zshrc
    source <(rack-gateway completion zsh)

    # Or add to your fpath
    rack-gateway completion zsh > "${fpath[1]}/_rack-gateway"
    ```
  </TabItem>
  <TabItem label="Fish">
    ```bash
    rack-gateway completion fish | source

    # Or save to completions directory
    rack-gateway completion fish > ~/.config/fish/completions/rack-gateway.fish
    ```
  </TabItem>
  <TabItem label="PowerShell">
    ```powershell
    # Add to your PowerShell profile
    rack-gateway completion powershell | Out-String | Invoke-Expression
    ```
  </TabItem>
</Tabs>

## Recommended Alias

Set up a short alias for convenience:

```bash
# Add to ~/.bashrc, ~/.zshrc, or equivalent
alias cg="rack-gateway"
```

Now you can use:
```bash
cg apps
cg deploy
cg logs -a myapp
```

## WebAuthn Support (Optional)

Security keys (WebAuthn/FIDO2) in the CLI need a build with libfido2. Install it before building from source:

<Tabs>
  <TabItem label="macOS">
    ```bash
    brew install libfido2
    ```
  </TabItem>
  <TabItem label="Ubuntu/Debian">
    ```bash
    sudo apt-get install libfido2-dev libudev-dev libusb-1.0-0-dev
    ```
  </TabItem>
  <TabItem label="Fedora/RHEL">
    ```bash
    sudo dnf install libfido2-devel systemd-devel libusb1-devel
    ```
  </TabItem>
  <TabItem label="Arch Linux">
    ```bash
    sudo pacman -S libfido2 libusb
    ```
  </TabItem>
</Tabs>

<Aside type="note" title="WebAuthn is Optional">
WebAuthn support is optional. Without it (the release build, or `task go:build:cli:nofido`), the CLI offers your
other MFA methods: an authenticator app (TOTP), a YubiKey OTP or a backup code.
</Aside>

## Building from Source

If you prefer to build from source:

<Steps>

1. **Prerequisites**
   - Go 1.26 or later
   - Git and [Task](https://taskfile.dev)
   - libfido2 (see [WebAuthn Support](#webauthn-support-optional)), unless you build without WebAuthn

2. **Clone and build**
   ```bash
   git clone https://github.com/docspring/rack-gateway.git
   cd rack-gateway
   task go:build:cli
   ```

3. **Install**
   ```bash
   sudo mv bin/rack-gateway /usr/local/bin/
   ```

</Steps>

### Building with WebAuthn Support

To build with WebAuthn/FIDO2 support, use the default CLI build:

```bash
task go:build:cli
```

### Building without WebAuthn

To build without WebAuthn support (smaller binary, no CGO):

```bash
task go:build:cli:nofido
```

## Updating

To update, download the new release (Linux x86_64), or rebuild from source:

```bash
cd rack-gateway
git pull
task go:build:cli
sudo mv bin/rack-gateway /usr/local/bin/
```

## Troubleshooting

### "command not found"

Make sure the binary is in your PATH:

```bash
which rack-gateway
# Should output: /usr/local/bin/rack-gateway
```

If not, either move the binary to a directory in your PATH, or add its location:

```bash
export PATH="$PATH:/path/to/rack-gateway"
```

### Permission denied

Make sure the binary is executable:

```bash
chmod +x /usr/local/bin/rack-gateway
```

### macOS security warning

On macOS, you may see a security warning the first time you run the CLI. Either:

1. Right-click the binary in Finder and select "Open", then click "Open" in the dialog
2. Or run: `xattr -d com.apple.quarantine /usr/local/bin/rack-gateway`
